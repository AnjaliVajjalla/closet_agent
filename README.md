# Closet Agent

A simple AI agent built with Python, smolagents, Qwen2, and Ollama that searches real Polyvore outfit data.

## What It Does

The agent can:
- Retrieve outfits from the Polyvore dataset
- Look up clothing item information
- Search outfits by clothing category
- Search using multiple categories
- Return structured outfit results
